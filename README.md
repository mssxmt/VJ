# VJ

ブラウザだけで動作する VJ ツール。オーディオ入力に反応して変形・飛散・発光・グリッチするプロシージャルなオブジェクトをリアルタイムに描画し、映像(音入り)の録画エクスポートまでブラウザ単体で完結します。

## 特徴

### 2つのパターン(ライブ切替)
- **Machine** — ボルト/ケーブル/ベンチ/支柱/棘など機械パーツの集合。明るいフラットメタル、オンセットで**分解(scatter)**
- **Organism** — 流体金属(クローム/水銀)の有機塊。滑らかなシェーディング、流れるチューブ、柔らかな脈動
- `machine.pattern`(トグル)/ `P` キーで切替

### オーディオリアクティビティ
- **スペクトラルフラックス + 帯域別解析**(低/中/高)でパーツをバラバラに駆動
- パーツごとに固有の escape方向・感度・減衰・**時間ラグ**で、同期しない有機的な飛散
- 低域キックでパーツが外向きにスライドしてスナップバック、高域でグリッター

### エフェクト
- **キックバースト** — 低域オンセットで衝撃波リング / パーティクル / 中心フラッシュ(各トグル)
- **EMPビーム** — 高域トランジェントでマシンの向きに追従して上下に伸びる電磁パルスビーム(照射瞬間に太く→細く、フェードアウト、スパーク付き)
- **ストレッチグリッチ** — オブジェクト全体を縦/横に極端に引き伸ばし
- ポストエフェクト: グリッチ / ブルーム / 色収差 / ノイズ / スキャンライン

### カメラ / 回転
- `Spin X/Y/Z` — オブジェクトを3軸で回転(MIDIで視点方向を操作可能)。AUTOでLFO自動駆動
- カメラ: 距離 / 軌道速度 / シェイク / FOV、AUTOでオンセット自動カット

### 録画エクスポート(音入り)
- **REC/STOP** + **形式選択(WebM / MP4)**
- **WebM** — フル解像度・VP9・即ダウンロード
- **MP4** — 停止後に ffmpeg.wasm で1080pトランスコード(正しい尺・音声入り・高互換性、変換に時間がかかります)

### 操作系
- **入力ソース選択** — デバイスドロップダウンでマイク/ライン入力/IFを直接選択(ファイル再生も)
- **MIDI ラーン** — 全パラメータをノブ/パッドに割当可能(localStorageに保存・JSON入出力)
- **AUTO モード** — LFO + オーディオ解析でパラメータ自動運転(machine / effects / camera を個別ON/OFF)
- **キーボードショートカット** — ライブ操作向け

## 動作環境

- **推奨ブラウザ**: Chrome / Edge(Web MIDI・MP4録画ともに対応)。FirefoxはWeb MIDI非対応
- WebGL2 対応の GPU / ブラウザ
- マイク/ライン入力を使う場合は入力デバイスへのアクセス許可が必要
- MP4エクスポートは停止後に ffmpeg.wasm コア(~30MB)をCDNからロードして変換します

## セットアップ

```bash
npm install      # 依存パッケージのインストール
npm run dev      # 開発サーバ起動 (http://localhost:5173)
npm run build    # プロダクションビルド
npm test         # ユニットテスト実行
```

## 操作方法

### キーボード

| キー | 動作 |
|------|------|
| `H` | UI パネルの表示 / 非表示 |
| `F` | フルスクリーン切り替え |
| `Space` | AUTO モードの ON / OFF |
| `R` | オブジェクトの再生成(ランダムシード) |
| `P` | パターン切替(Machine ↔ Organism) |
| `E` | EMP ビームの ON / OFF |
| `G` / `B` | グリッチ / ブルームのパルス |
| `1`–`9` | プリセットシードに切り替え |

### オーディオソース

パネル左上のドロップダウンで入力デバイスを選択(選択=開始、初回のみ許可プロンプト)。`— input off —`で停止。
- **マイク / ライン入力** — 選択したデバイスを解析ソースに(スピーカーには出力されません)
- **File** — ローカル音声ファイルを再生しながら解析(スピーカーにも出力)

### MIDI ラーン

1. 割り当てたいパラメータの横の `M` ボタンをクリック
2. MIDI コントローラのノブ/ボタンを動かす
3. そのコントロールがパラメータに割り当てられます

マッピングは localStorage に保存され、次回起動時に自動復元されます。

### 録画

1. 形式(WebM / MP4)を選択
2. **REC** で録画開始、**STOP** で停止
3. WebM は即ダウンロード、MP4 は変換後にダウンロードされます
